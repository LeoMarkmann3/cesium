    MTMeasure — usage

    Measurement app for multi-temporal 3D Tiles point clouds. It has exactly two modes: auto=1 runs the measurement protocol and downloads two CSVs, record=1 records a camera path. Without either it just shows this page.
    Parameter Default Meaning
    tileset — (required) Tileset URL, absolute or relative to this page.
    name last path segment Label used in rows and in the CSV filenames.
    path generated URL of a camera-path JSON. Without it, a three-waypoint traverse is generated from the tileset's bounding sphere.
    speed path JSON, else 15 Camera speed in m/s along the path (URL wins over JSON).
    laps 2 Sequential epoch-sweep laps per waypoint.
    randomSwitches epoch count Seeded-random epoch switches per waypoint, after the laps.
    seed 42 PRNG seed for the random switch order; recorded in every row.
    sse Cesium default maximumScreenSpaceError override.
    cacheMB Cesium default cacheBytes override, in MB.
    auto off auto=1: run the protocol, then download mtmeasure_<name>.csv and perf_<name>.csv.
    record off record=1: record a camera path (mutually exclusive with auto).
